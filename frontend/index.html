About this project

A college project showing OOP, data structures and algorithms and file handling in C++17. It simulates basic banking and must not be used for real money or real customer data.

  • Accounts live in a hand-written singly linked list.
  • Undo uses a hand-written stack (last in, first out).
  • Service tokens use a hand-written queue (first in, first out).
  • Sorted view uses a hand-written merge sort.
  • Storage is plain text files in the data/ folder; money is kept as integer paise.
  • Backend is C++ (cpp-httplib + nlohmann/json); this page only calls its JSON API.
